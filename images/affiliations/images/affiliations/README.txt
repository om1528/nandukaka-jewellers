NANDUKAKA JEWELLERS WEBSITE

1. Put logo at: images/logo.png
2. Put jewellery photos in the correct category folder.
3. Add photo paths in image-list.js.
4. Open index.html or run with VS Code Live Server.
5. After checking, push the same folder to your existing GitHub repository.

Example photo:
images/gold/gents/rings/ring-01.jpg

Then in image-list.js:
jewelleryImages.gold.gents.rings = [
  "images/gold/gents/rings/ring-01.jpg"
];
